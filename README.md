# کونەمێروو — Landing Page

لاپەڕەیەکی سووک بۆ یاریی وشە کوردییەکان. HTML + CSS + JS سووک — گونجاو بۆ **GitHub Pages**.

## پێش بڵاوکردنەوە

لە `index.html` لینکی تێلێگرام بگۆڕە:

```html
href="https://t.me/kunemerubot"
```

## GitHub Pages

1. ئەم فۆڵدەرە بکە بە repo لە GitHub
2. **Settings → Pages → Source:** `Deploy from a branch`
3. Branch: `main` / folder: `/ (root)`
4. دوای چەند خولەک سایتەکەت چالاک دەبێت لە:
   `https://USERNAME.github.io/REPO_NAME/`
